# Secure WordPress VPS Project

โปรเจกต์ติดตั้ง WordPress บน VPS สำหรับประชาสัมพันธ์หลักสูตรวิทยาการคอมพิวเตอร์

## Objectives
- ติดตั้ง WordPress บน VPS
- ตั้งค่า SSH Key Authentication
- ปิด Root Login และ Password Authentication
- ตั้งค่า HTTPS ด้วย Let's Encrypt
- จำกัดการเข้าถึงเว็บไซต์ด้วย Firewall
- ออกแบบเว็บไซต์แนะนำหลักสูตรวิทยาการคอมพิวเตอร์

## Technology Stack
- Ubuntu Server
- Nginx
- PHP
- MariaDB
- WordPress
- DuckDNS
